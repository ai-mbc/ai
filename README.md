## 앞으로의 기록 방식

대표 실습을 정리할 때는 학습 목표, 배운 점, 막힌 점과 해결 방법, 프로젝트에 적용한 내용을 함께 기록합니다. 수업 예제와 직접 수정한 부분을 구분해 학습 과정을 보여줄 계획입니다.

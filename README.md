## 보는 방법

관심 있는 주제의 폴더에서 코드와 노트북을 확인하세요. 실습마다 사용하는 패키지·데이터·환경이 다를 수 있으므로 실행 전 해당 파일의 설명과 경로를 확인해야 합니다.

## 앞으로의 기록 방식

대표 실습을 정리할 때는 학습 목표, 배운 점, 막힌 점과 해결 방법, 프로젝트에 적용한 내용을 함께 기록합니다. 수업 예제와 직접 수정한 부분을 구분해 학습 과정을 보여줄 계획입니다.
